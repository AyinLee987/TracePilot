## 发现与处置

| 发现 | 核对与处置 |
| --- | --- |
| 原反馈按响应序号映射，非末尾 conclusion 可错位 | 改用每行 `recorded_step` 映射；保留 conclusion 独立行 |
| 未知工具名可能被算成正常动作 | 本批只有 5 个已知工具名；增加显式拒绝未知名，不静默分类 |
| 只看完成请求可能漏掉失败时间 | 扫描全部事件：384 open/close、12,521 dispatch/complete，无其他事件；增加事件类别与完整结算检查 |
| 末尾未闭合错误段影响恢复率解释 | 新增 `open_at_run_end`；正式 Flash/Pro 分别 35/26 段，全部段/已闭合段的恢复比例分别报告；不推断截断后永远不能恢复 |
| 分数守恒不是独立真值 | 说明为内部一致性；真正交叉证据是环境操作顺序、无未观测分差及最终 signed score 一致 |
| 公开数据范围措辞偏强 | 改成含截断动作参数，不含完整响应/原反馈正文；内联版称摘要版 |
| 图横轴和时间负刻度 | 横轴明确是最大步数兼逻辑时限倍率；HTTP 下界固定 0 |
| 溯源及输出范围 | 查看器核对源轨迹哈希；验证记录含分析/绘图/模板/输出哈希；docstring/README 明确固定输出及单写者 |
| CDN/SRI 和多文件原子输出 | 保留版本固定的 D3 CDN 并说明联网依赖；本批只读离线串行用途不扩为通用发布系统。暂不增加事务目录或本地 vendor |
