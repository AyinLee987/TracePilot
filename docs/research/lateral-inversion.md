# 候选生成：反转假设

使用用户指定的 lateral 技能，按其路由选择一次 inversion。对象是“从时间感知 Agent 的缺口形成论文”的研究方案；这不是代码审查或科学证据。

| 原假设 | 可辩护的反向假设 | 何处成立／证据边界 | 处置 |
| --- | --- | --- | --- |
| 充分使用时间预算就更符合用户目标 | 提前交付可用结果可能比耗尽预算更有价值 | 交互式问答与随时可能被中断的任务；具体收益需实验，不能等同 Timely 的目标 | 保留：可用答案随时间的质量曲线，而不只看最后一次输出 |
| 模型获得时间提示后就知道还有多少时间 | 时间信息本身可能延迟、偏差或与真实终止时钟不一致 | 分布式请求的排队/网络等待、客户端截止；具体实现需核对 | 保留：时钟信号可靠性及时间感知策略的校准 |
| 相同平均工具延迟代表相同执行条件 | 同均值不同尾部/相关性可能需要不同策略 | 限时任务遇到服务抖动；是否改变模型行为仍待验证 | 保留：时延分布外泛化，必须有固定行为零模型 |
| 检测停滞即可决定升级 | 升级本身可能没有收益或加重历史负担 | Calibration Is Not Control、The Handoff Tax 已有直接研究 | 淘汰为独立新主张：仅复用作对照与设计纪律 |
| 基础模型必须重新训练才会理解时间 | 外部终止/调度与简单提示可能解释大部分收益 | 可比较提示基线、硬截止和动作约束；不能预设一定有效 | 保留为基线，暂不当独立方法创新 |
| 越完整的 trace 就越容易决定下一步 | 少量有动作价值的信号可能已经足够 | 已有轻量路由与干预研究 | 淘汰为宽泛主张：需要具体新效应，不能只做特征裁剪 |
| 质量/正确性需要独立评价 | 只看响应速度或 trace 外观也可证明 Agent 更好 | 在本项目要主张任务能力—时间权衡的范围内，找不到可靠成立条件；代理指标不能代替结果 | 反转失败：保留独立结果评分这个原假设 |

跨候选的共同点：时间不仅是剩余资源，也是一个被测量、被反馈、被终止规则解释的信号。先分离“信号”“动作改变”“最终效用”，再判断是否需要新 router。

暂时优先审查前两项，时延分布为备选。排名仅指导今晚查证，不证明创新，也不要求最终一定选择这些候选。
